## 🕹️ Overview

EmoTracker is a highly configurable tracker for randomizer runs, with community-made packs for hundreds of games tracking items, locations, and logic automatically.

Whether you're a newcomer or a veteran, EmoTracker provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
